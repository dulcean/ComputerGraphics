# 💎labw3💎

Лабораторная работа 3. Базовые растровые алгоритмы

## 💎Task💎

Закрепить теоретический материал и освоить основные возможности базовых алгоритмов растеризации отрезков и кривых:

- Пошаговый алгоритм
- Алгоритм ЦДА
- Алгоритм Брезенхема
- Алгоритм Брезенхема (для окружности)
- Алгоритм Кастла-Питвея
- Алгоритм Ву

## 🛠 Использованные средства разработки

- Фреймворк: **Flutter**
- Язык: **Dart**

## 🔄 Ход работы

1. Создан класс `GridPainter`, отвечающий за коорд.сетку.
2. Создан класс `MainScreen` -- методы отрисовки главной страницы + `lineAnimator`.
3. LogConsole для логирования CallBack алгоритмов
4. Реализация алгоритмов
5. Минимальный рефакторинг

## ⏱ Временные характеристики

Наибольшие поддерживаемые входные данные для отрезка:

- `x1 = -100`, `y1 = -75`
- `x2 = 100`, `y2 = 75`

Для окружности:

- `x0 = 0`, `y0 = 0`, `R = 75`

Для Кастла-Питвея:

- `x1 = -100`, `y1 = -75`
- `x2 = 100`, `y2 = 75`
- `iters = 100`

| Алгоритм                           | Algorithm Callback       |
|------------------------------------|--------------------------|
| Пошаговый алгоритм                 | 320 мкс                  |
| Алгоритм ЦДА                       | 244 мкс                  |
| Алгоритм Брезенхема                | 465 мкс                  |
| Алгоритм Кастла-Питвея             | 201 мкс                  |
| Алгоритм Ву                        | 409 мкс                  |
| Алгоритм Брезенхема для окружности | 573 мкс                  |

- Алгоритм ЦДА — подходящий выбор для быстрой и простой реализации.
- Ву и Брезенхема могут использоваться, если требуется сглаживание линий.
- Алгоритм Брезенхема для окружности остается полезным для создания окружностей, несмотря на сравнительно высокое время выполнения.
